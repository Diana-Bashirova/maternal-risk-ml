##  О проекте

**Maternal Risk Classifier (MRC)** — это прогностическая модель машинного обучения, предназначенная для автоматической триажной сортировки беременных женщин по трём классам риска:

| Класс | Описание |
|-------|----------|
|  `low risk` | Низкий риск осложнений |
|  `mid risk` | Средний риск осложнений |
|  `high risk` | Высокий риск осложнений |

Модель разработана с учётом **клинических требований** и **бизнес-ограничений**, с приоритетом на безопасность пациенток.

---

##  Бизнес-задача

### Клинический контекст
Пренатальная диагностика является критически важным этапом ведения беременности. Своевременное выявление пациенток с высоким риском осложнений (преэклампсия, гестационный диабет) позволяет предотвратить серьёзные последствия как для матери, так и для ребёнка.

### Ключевые требования
1. **Безопасность превыше всего**: пропуск высокого риска (False Negative) в 10 раз дороже ложной тревоги (False Positive)
2. **Возрастные ограничения**: пациентки >42 лет автоматически направляются к специалисту
3. **Многоуровневая система**: неуверенные решения передаются на ручную проверку врачу

### Входные признаки
- `Age` — возраст пациентки
- `SystolicBP` / `DiastolicBP` — систолическое и диастолическое давление
- `BS` — уровень сахара в крови
- `BodyTemp` — температура тела
- `HeartRate` — частота сердечных сокращений

##  Архитектура решения

### Гибридная модель
```
┌─────────────────────────────────────────────────────────┐
│                  ВХОДНЫЕ ДАННЫЕ ПАЦИЕНТКИ                │
└─────────────────────────────────────────────────────────┘
                            │
                            ▼
              ┌───────────────────────────┐
              │   Возраст > 42 лет?       │
              └───────────────────────────┘
                    │              │
                   YES            NO
                    │              │
                    ▼              ▼
        ┌───────────────┐   ┌──────────────────┐
        │ БИЗНЕС-ПРАВИЛО│   │   ML-МОДЕЛЬ      │
        │ Направление к │   │  (XGBoost +      │
        │ специалисту   │   │   Pipeline)      │
        └───────────────┘   └──────────────────┘
                                    │
                                    ▼
                         ┌─────────────────────┐
                         │  max_proba >= 0.50? │
                         └─────────────────────┘
                              │           │
                             YES         NO
                              │           │
                              ▼           ▼
                    ┌─────────────┐ ┌──────────────┐
                    │ АВТО-РЕШЕНИЕ│ │ РУЧНАЯ       │
                    │ (low/mid/   │ │ ПРОВЕРКА     │
                    │  high risk) │ │ врачом       │
                    └─────────────┘ └──────────────┘
```

### Компоненты пайплайна
1. **IterativeImputer (MICE)** — многомерная импутация пропусков
2. **Feature Engineering** — создание `PulsePressure` и индикаторов пропусков
3. **XGBClassifier** — многоклассовый классификатор (`tree_method='hist'`)
4. **SHAP** — интерпретация решений

### 5. Использование модели
```python
import joblib
import pandas as pd

# Загрузка модели
pipeline = joblib.load('models/mrc_pipeline.pkl')

# Пример данных пациентки
patient = pd.DataFrame([{
    'Age': 28,
    'SystolicBP': 120,
    'DiastolicBP': 80,
    'BS': 95,
    'BodyTemp': 36.8,
    'HeartRate': 78
}])

# Предсказание
proba = pipeline.predict_proba(patient)[0]
pred_class = pipeline.predict(patient)[0]

print(f"Класс риска: {pred_class}")
print(f"Уверенность: {max(proba):.2%}")
```

##  Интерпретируемость

Модель использует **SHAP (SHapley Additive exPlanations)** для объяснения решений:

### Глобальная важность признаков
Наиболее значимые клинические показатели:
1.  **SystolicBP / DiastolicBP** — ключевой индикатор преэклампсии
2.  **BS (уровень сахара)** — индикатор гестационного диабета
3.  **Age** — фактор общего риска
4.  **HeartRate** — дополнительная информация

### Локальная интерпретация
Waterfall-график показывает вклад каждого признака в конкретное решение, что позволяет врачу:
- Проверить клиническую обоснованность предсказания
- Понять, почему модель приняла именно такое решение
- Выявить потенциальные ошибки

##  Ограничения и этика

### Известные ограничения
-  Модель **не применяется** для пациенток младше 18 лет
-  Для пациенток **старше 42 лет** работает только бизнес-правило
-  Не учитываются: BMI, срок беременности, протеинурия
-  Часть обучающей выборки — синтетические данные
-  Порог 0.50 требует калибровки на реальных данных

### Этические принципы
-  **Приоритет безопасности**: Recall@HighRisk = 1.00
-  **Прозрачность**: SHAP-объяснения для каждого решения
-  **Защита уязвимых групп**: возрастные пациентки — только к специалисту
-  **Клиническая валидация**: A/B-тестирование перед внедрением

### Допустимое использование
> Модель предназначена **исключительно для поддержки принятия клинических решений (Clinical Decision Support)**. Она **не должна** использоваться как единственный источник истины для постановки окончательного диагноза без участия квалифицированного медицинского персонала.
